# Scheda Calisthenics – Web App

App statica mobile-first per GitHub Pages.

## Pubblicazione su GitHub Pages
1. Crea un nuovo repository pubblico (es. `calisthenics`).
2. Carica **tutti i file contenuti in questa cartella** nella root del repository.
3. Vai in Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, cartella `/ (root)`.
6. Salva e attendi la pubblicazione.

## Uso sul telefono
- Android/Chrome: menu → Aggiungi a schermata Home / Installa app.
- iPhone/Safari: Condividi → Aggiungi alla schermata Home.

## Aggiornamenti futuri
